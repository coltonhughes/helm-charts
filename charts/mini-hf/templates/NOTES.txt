Mini-HF has been installed.

Check the migration Job and workloads:
  kubectl get jobs,deployments,httproutes -n {{ .Release.Namespace }}

Configure the four routes under routes.ui, routes.management, routes.hf, and
routes.modelscope with Gateway API parent references and hostnames. Set
publicURLs to the externally reachable URLs used by browsers and clients.

Ensure S3 endpoint, bucket, access key, and secret key are configured. The S3
bucket must exist before Mini-HF can store models.
